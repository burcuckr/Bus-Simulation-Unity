# 🚌 Bus Simulation

### A Simple Low-Poly Bus Simulation Project

A small 3D bus simulation project developed with **Unity and C#** during my internship. The project focuses on basic bus movement, camera following, and passenger pickup mechanics in a low-poly city environment.

---

## 🎮 Project Overview

The player controls a bus in a simple 3D city environment, navigates through the streets, approaches bus stops, and picks up waiting passengers using an interaction key.

## ✨ Implemented Features

- 🚍 Basic bus movement at a fixed speed
- 🔄 Basic directional rotation and steering
- 🎥 Third-person camera follow system
- 👥 Passenger detection using trigger colliders
- 🎯 Passenger pickup using the E key
- 🛣️ Basic movement boundary restrictions
- 🎨 Low-poly 3D city environment

## 🛠️ Technologies Used

- Unity
- C#
- Unity Input System
- Unity Physics System

## 🎮 Controls

| Input | Action |
|---|---|
| Movement Keys | Move and turn the bus |
| E | Pick up a passenger |

## 📚 What I Practiced

- Basic movement mechanics using C#
- Working with Unity's Input System
- Camera positioning and rotation
- Collision and trigger detection
- Interacting with GameObjects
- Using `OnTriggerEnter()` and `OnTriggerExit()`
- Implementing passenger pickup mechanics

## 🚧 Project Status

**Completed – Basic Learning Project**

This project was developed as part of my Unity learning journey during my internship.

It features a simple bus movement and rotation system with a fixed movement speed. It does not include realistic vehicle physics, acceleration, braking, or animated wheel rotation.

The main purpose of this project was to practice fundamental Unity concepts, work with GameObjects, implement camera following, and develop basic gameplay interactions.
